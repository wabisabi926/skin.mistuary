# Mistuary（雾汐）

**Mistuary（雾汐）**，专为中文用户打造的 Kodi 22 轻量透明皮肤，衍生自 Estuary N，小而美。  
透黑 / 透白双主题，页面 / 弹窗 / 播放中三档透明度各 6 级，原版 Kodi 22 直接运行。

**一键接入 Emby**：装好 **Emby for Kodi Next Gen** 并登录，媒体库整体同步进 Kodi ——
电影 / 剧集 / 季 / 集 / 评分 / 库封面开箱即用，无需手动整理。

> 依赖插件 **Mistuary Helper**（`addon.xml` 硬依赖，未安装时皮肤不加载）。请先装插件再切皮肤。

## 亮点

- **专为中文用户打造**：豆瓣评分、全拼 / 拼音首字母搜索、服务端中文演员名与类型搜索、  
  手机 App 文本注入，由 Mistuary Helper 统一提供。
- **一键接入 Emby**：E4KNG 登录即同步，与 Emby 应用内观感一致；神医助手（StrmAssistantPlus）  
  写入的豆瓣类型评分同样被读取。
- **免魔改内核**：全部用标准控件 + 贴图实现，Windows / Linux / CoreELEC / Android 通用。
- **小而快**：极度精简，焦点移动无拖影，切视图不掉帧。
- **皮肤零脚本**：皮肤本体只有 XML 与贴图，HTTP / JSON 全部在 Mistuary Helper。
- **三档透明度互不影响**：页面管全屏页面与卡片，弹窗管对话框、菜单、键盘，播放中管 OSD、  
  播放列表、书签 —— 多数皮肤只有一个总开关。

## 安装

1. 到 [Releases](https://github.com/wabisabi926/skin.mistuary/releases) 下载最新 `skin.mistuary-x.y.z.zip`
2. Kodi → 设置 → 插件 → 从 zip 文件安装
3. 设置 → 界面 → 皮肤 → 皮肤 → 选 **Mistuary**

手动安装：整个仓库目录放到 Kodi 的 `addons/` 下，目录名改成 `skin.mistuary`，重启 Kodi。

## 升级与回退

直接装新版本 zip，Kodi 提示「已安装，是否覆盖」选是；皮肤设置存在  
`userdata/addon_data/skin.mistuary/`，覆盖安装不丢。回退到旧版同理，从  
[Releases](https://github.com/wabisabi926/skin.mistuary/releases) 取旧 zip。  
**1.5.2 起要求 Kodi 22**，回 Kodi 21 需用 1.5.1 或更早。

## 一键接入 Emby

1. 安装 **Emby for Kodi Next Gen**（E4KNG，Emby 官方 Kodi 插件）并登录
2. 安装 [Mistuary Helper](https://github.com/wabisabi926/script.mistuary.helper/releases)
3. 设置 → 界面 → 皮肤 → 皮肤 → 选 **Mistuary**（或重载皮肤）

| 能力                                    | 来源                                                         |
| ------------------------------------- | ---------------------------------------------------------- |
| 媒体库、季集结构、已看状态、续播点                     | E4KNG 同步                                                   |
| 媒体库封面（按库名自动显示）                        | Mistuary Helper 从 Emby 同步                                  |
| 豆瓣类型评分                                | StrmAssistantPlus 写入 Emby → **Emby for Kodi Next Gen** 同步；详情页由 Helper 兜底 |
| 首页 / 列表的类型化豆瓣分（亮豆瓣绿环）                | 官方 E4K 只同步 default 评分，类型化豆瓣分需本仓库的 E4K fork                |
| 服务端搜索（中文 / 原名 / 全拼 / 首字母 / 英文人名 / 类型） | Mistuary Helper 走 Emby 服务端                                 |

## 必需插件：Mistuary Helper

详情页豆瓣评分、Emby 服务端搜索、媒体库封面同步、播放列表补全由 Mistuary Helper 提供，  
`addon.xml` 硬依赖：**未安装时皮肤不加载**。

1. 从 [Mistuary Helper Releases](https://github.com/wabisabi926/script.mistuary.helper/releases)  
   下载 `script.mistuary.helper-<ver>.zip`
2. Kodi → 插件 → 从 zip 安装，在「我的插件 → 程序插件」里启用
3. 设置 → 界面 → 皮肤 → 皮肤 → 选 **Mistuary**（或重载皮肤）

> 装 / 卸插件后不重载皮肤，新分支不生效。搜索还需 **Emby for Kodi NextGen**；  
> 豆瓣评分只需 IMDb id（或库内豆瓣 ID）。建议 **0.5.3+**：英文人名与类型搜索扩展、  
> 豆瓣分优先读 StrmAssistantPlus 快照（减少直连限流）、背景剧照色光底（0.5.0）、  
> 未同步剧集浏览（0.4.0）。相关开关在皮肤设置的「媒体」「播放」页。

## 主要功能

|          |                                                                                       |
| -------- | ------------------------------------------------------------------------------------- |
| **界面**   | 真圆角海报墙（遮罩逐像素裁切，非色块盖角）、焦点环贴边、详情页全屏沉浸、演员栏点开                                             |
| **背景**   | 影视页剧照铺满全屏；当前剧照经 Helper 高斯模糊成色光底，从清晰剧照左缘渗出（35% 淡色光）；底层压暗四档可调（「设置 → 外观 → 背景压暗」，默认 0.50） |
| **剧集**   | 点开电视剧直接进入剧集详情页版式：季标签与本季集卡片同屏，切换季即换集；所有电视剧入口一致                                         |
| **评分**   | 评分胶囊（豆瓣 / IMDb / TMDB）：主评分四档可选，详情页豆瓣评分独立开关，一行最多两颗；豆瓣优先读 E4K 同步的类型评分，详情页读不到时 Helper 兜底 |
| **搜索**   | 服务端搜索支持中文 / 原名 / 全拼 / 首字母 / 英文人名 / 类型；输入框可呼出全键盘，中文直写，兼容手机 App 文本注入                    |
| **音乐**   | 播放页右侧歌词（CU LRC）、黑胶唱片模式、可替换播放背景、OSD 闲置自动隐藏（时长可调）                                       |
| **播放**   | Helper 补全同季 / 同目录 / 跨季后续队列；电视剧详情页起播直接全屏                                               |
| **文件续播** | 文件管理器播过的视频记住进度：起播询问「继续播放 / 从头播放」，焦点行显示已播比例圆环（Helper 提供，不写 Kodi 原生续播点）                 |
| **系统**   | 电源菜单按平台能力自动显隐；设置中心合并 Kodi 原生设置与皮肤选项                                                   |

## 透黑 / 透白

同一套玻璃，两种压色方向，在「设置 → 界面 → 皮肤 → 颜色」切换：

- **透黑**（`SKINDEFAULT`，默认）：玻璃压黑，暗环境不刺眼 —— 皮肤的常态
- **透白**（`light`）：玻璃提白，亮环境更清爽

面板分 6 级明暗，由「皮肤设置 → 界面」的三个透明度设置控制；两种模式下文字均为白色。

## 常改的几个设置

设置页底部有帮助条：聚焦哪一行显示哪一行的说明。最常动的几项：

| 设置                   | 位置        | 管什么                                                  |
| -------------------- | --------- | ---------------------------------------------------- |
| **页面 / 弹窗 / 播放中透明度** | 皮肤设置 → 界面 | 三档各 6 级，互不影响（见「亮点」）                                  |
| **主评分来源**            | 皮肤设置 → 媒体 | TMDb / IMDb / 豆瓣 / 自动；选「豆瓣」需 StrmAssistantPlus 写分入 Emby 且 E4K 同步该类型 |
| **详情页显示豆瓣评分**        | 皮肤设置 → 媒体 | 开关。开启后详情页在主评分之外追加豆瓣胶囊（2.3.0 起取代原「次评分来源」）             |
| **背景压暗**             | 皮肤设置 → 外观 | 剧照底层与阅读遮罩四档：0.35 / 0.50 / 0.60 / 1.00                |
| **媒体标识**             | 皮肤设置 → 媒体 | 关闭后不再显示 4K / HDR / 音轨图标                              |
| **自动滚动**             | 皮肤设置 → 界面 | 长标题、长简介自动滚动                                          |

> 评分一行最多两颗：主评分 + 豆瓣。列表页只显示主评分；详情页由「显示豆瓣评分」开关控制第二颗，同值不重复显示。



## 已知限制

- **不维护天气、电台、游戏界面**：只保留视频、音乐、图片、PVR、插件
- **只维护中英双语**：其他语言显示英文
- **详情页点演员看作品需 `script.embuary.info`**：未装时提示安装（可拒绝）
- **本地搜索只匹配标题 / 原名 / 拼音首字母**：中文演员名与类型需服务端桥（Helper 0.3.3+）
- **首页 / 列表的豆瓣分依赖库内评分类型**：官方 E4K 只同步 default 评分，没有 douban 类型时首页 / 列表只能把豆瓣分当主评分数值显示（识别不出豆瓣、环色不亮绿）；类型化豆瓣分由本仓库的 E4K fork 提供。详情页不受影响，Helper 可联网兜底

## 常见问题

**装了皮肤没变化，还是原来的皮肤**  
设置 → 界面 → 皮肤 → 皮肤 → 选 **Mistuary**。刚换过版本号或依赖声明的，需**完全退出 Kodi 再打开**。

**背景全黑，没有剧照**

1. 查 皮肤设置 → 艺术图片 → 是否关掉背景图相关开关
2. 确认 Emby 提供了 fanart（纯本地刮削的库可能没有）
3. 搜索页背景是「渐变 + 随机剧照」，属设计

**技术标识（4K / HDR / Atmos）不显示**

1. 确认 Kodi 是 **22**（设置 → 系统信息）
2. 确认片源本身带这些信息 —— 纯 Kodi 刮削的库只有分辨率
3. 剧集和季在列表里用「当前季第一集」代表；整部剧无单集数据时为空

**详情页没有豆瓣评分**  
需装 **Mistuary Helper**（硬依赖），片子要有 IMDb id（或库内豆瓣 ID）。  
要和 Emby 应用内一致的分数，需装 StrmAssistantPlus：Helper 优先读它的接口快照，  
未装时直连豆瓣公开接口，可能被限流。

**搜索没有结果，或只搜得到本地内容**

- 服务端搜索需 **Emby for Kodi NextGen** + **Mistuary Helper** 都装好
- 只装皮肤走本地搜索，只匹配标题、原名、拼音首字母
- 中文演员名、类型、英文人名只有服务端模式支持

**换透明度后没反应**  
三档透明度各管一摊：调「页面透明度」时播放 OSD 不变，那由「播放中透明度」管。
