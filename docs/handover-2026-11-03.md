## 2. 近期约定（已写进长期文档）

- **changelog 写法**：一条一行、尽量 ≤40 字，用 Kodi 术语（窗口 / 控件 / grouplist / label /
  fanart / OSD / 底板），数值只写「旧 → 新」；抽样数量、根因、调研过程留在 `docs/`（HANDOVER §6）
- **背景遮罩**：真剧照压暗、`primary.jpg` 兜底不压暗；判据是 `Includes_Home.xml` 的三条
  `expression`（`NaraHomeFanartSubItems` / `SubHero` / `SubOther`），详见 HANDOVER §5.11
- **表达式里禁止 `$EXP[...]` / `$VAR[...]` / `$INFO[...]` / `$MAP[...]`**：Kodi
  `InfoExpression::Parse` 把 `[` / `]` 当分组符，operand 注册失败后整条判 `false`；
  表达式之间也不能互引，只能由 `<visible>` 直接引用
- **电源菜单高度**：改任何按钮显隐都要同步改 `NaraPowerMenuLayout` 的底板高度表；
  CE 多「重启到安卓」一行，所以 CE 十六条全部 +60（HANDOVER §5.14 附近）
- **评分胶囊尺寸**：方形 108 / IMDb 126、文字框 56、居中、底板 30%（HANDOVER §5.14）
- **播放/暂停图标**：音乐 OSD 与视频 OSD 共用 `osd/nara/play.png|pause.png`，50×50（HANDOVER §5.12）
- **OK 弹窗**：`CGUIDialogOK` 固定加载 `DialogConfirm.xml`，改它 = 改所有 OK 弹窗（HANDOVER §5.13）
