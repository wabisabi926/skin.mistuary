## 2. 今天之外的近期约定（已写进长期文档）

这些不是今天改的，但和今天动的地方直接相关，动之前先看：

- **changelog 写法**：一条一行、尽量 ≤40 字，用 Kodi 术语（窗口 / 控件 / grouplist /
  label / fanart / OSD / 底板），数值只写「旧 → 新」；抽样数量、根因、调研过程留在
  `docs/`，不进 changelog（HANDOVER §6）
- **背景遮罩**：真剧照压暗、`primary.jpg` 兜底不压暗；判据是
  `Includes_Home.xml` 的三条 `expression`（`NaraHomeFanartSubItems` / `SubHero` / `SubOther`），
  详见 HANDOVER §5.11
- **表达式里禁止 `$EXP[...]` / `$VAR[...]` / `$INFO[...]` / `$MAP[...]`**：
  Kodi `InfoExpression::Parse` 把 `[` / `]` 当分组符，operand 注册失败后整条表达式判 `false`；
  表达式之间也不能互引，只能由 `<visible>` 直接引用
- **播放/暂停图标**：音乐 OSD 与视频 OSD 共用 `osd/nara/play.png|pause.png`，
  两边都是 50×50、`text_primary`；音乐主键不再加白色实心圆底（HANDOVER §5.12）
- **OK 弹窗**：Kodi 的 `CGUIDialogOK` 固定加载 `DialogConfirm.xml`，
  标题/正文左内边距 48、正文 top 92 / 宽 837 / 高 155，右上 vendor 图标 32×32
  （right 48、top 30，与标题中心对齐）。改它 = 改所有 OK 弹窗（HANDOVER §5.13）
- **状态图标**：海报卡与海报墙统一左下 28×28，图标走 `ItemStatusIconVar`、
  颜色走 `StatusIconColorVar`；只有真的看完才绿
