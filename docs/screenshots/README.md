## 还缺（等实机截图）

README 目前只有一张图标一览，缺**真实界面截图**。要补的话按下表拍，
文件名用括号里那个，直接放进本目录，我再改 README 引用。

| 优先级 | 拍什么 | 文件名 | 要求 |
|---|---|---|---|
| 1 | **首页**（继续观看 + 媒体库两行，带 fanart 背景） | `home.png` | 全屏，2160×1080 或 1920×1080 |
| 2 | **详情页**（大海报 + 评分胶囊 + 技术标识 + 简介） | `info.png` | 同上，最好挑一部带杜比视界的片子，能显示 4 枚标识 |
| 3 | **海报墙**（7 列，能看出圆角和焦点环） | `wall.png` | 同上 |
| 4 | **透明度对比**（同一页面「平衡」vs「实心」两张） | `opacity-a.png` / `opacity-b.png` | 同一页面、同一部片，只改透明度设置 |

### 怎么拍

- **Kodi 内置截图**：按 `PrintScreen`（Windows）或 `F11`，存到 Kodi 的临时目录；
  也可以在 设置 → 系统 → 日志 里找"截屏"按钮
- **Windows 通用**：`Win + Shift + S` 区域截图，或 `Alt + PrintScreen` 截当前窗口
- **别用手机拍屏幕** —— 会有摩尔纹和反光，README 上很难看

### 拍之前清掉这些

- 播放进度条、OSD（等它自动消失）
- 通知弹窗（Kodi 右下角）
- 调试用的红色标注、半透明遮罩
- 个人隐私：文件名里带本地路径的、私人片源名字的（可以换一部大众片）

## 注意

zip 体积。但为了 GitHub 页面加载速度，单张控制在 500 KB 以内，宽不超过 2000px。
