## 3. 踩坑

1. `compact_split` 是**结构分路**参数：默认值 false 写在 include，11 个影视实例显式 true。
   漏改一处就出现「首页错位」或「影视页评分行消失」。
2. `ratings_top` 在两条路径里含义不同：`compact_split=false` 时是评分行，
   `true` 时是元数据行。改这个值前先确认走哪条路。
3. 简介框高 **91** 是算间距的锚点；以后动 `plot_top` 或简介高度必须重算 `tech_top`。
4. 代表集参数必须「默认值 + 调用方传值」成对维护，单测已锁死，别只改一边。
