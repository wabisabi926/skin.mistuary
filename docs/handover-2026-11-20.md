## 3. 踩坑记录（下次省时间）

**① F5 必须先确认 Kodi 是前台窗口**
- 否则 `keybd_event(VK_F5)` 发给别的窗口，日志不会出现新的 `skin loaded`，会误判「改动没生效」。
- 可靠做法：`AttachThreadInput + ShowWindow(9) + SetForegroundWindow + BringWindowToTop`，
  发键后**以 `kodi.log` 里 `skin loaded` 时间戳变化为准**，不要看画面（可能是旧帧）。
- 单次常不生效，需循环重试。PowerShell 的 `Add-Type`、COM(`WScript.Shell`) 都被安全策略拦，只能走 ctypes。

**② `WidgetListCategories` 的 `item_top` 默认 20**
- 卡片从 `item_top` 起画。`item_height` 缩到等于 `card_height` 时必须把 `item_top` 设 0，
  否则卡片下半部超出 panel 被裁——**表现为整行卡片消失**。

**③ `HomeVideoTailRow` 行高是固定值**
- 原本 260，两行 520。`top` 下移后可用高度不足时，「类别」行会被挤出屏幕。
- 行高必须 ≥ `header_height + panel_top + panel_height`。

**④ 隐藏 wraplist 会抢焦点（与轮播不可兼得）**
- 详见 §4.2。官方 K22 上做不了「Hero 自动轮播」。

### 4.2 已判定「不做」的事（别重试）

**① 电影/电视剧页 Hero 自动轮播 —— 官方 K22 做不到**
- 思路：隐藏 1×1 wraplist + `autoscroll` 驱动，Hero 读 `Container(x).ListItem`。数据层能跑
  （实测 5 部每 5 秒轮换、标题与背景同步）。
- **但隐藏 wraplist 必然抢焦点**（↓ 落到它上面，左右能换项），**一旦有焦点 autoscroll 就暂停**。
  两者不可兼得。RC2 靠魔改内核的「稳定选中项」扩展才做得了。
- 试过且失败的 6 种：放 group 末尾 / `ondown` 指 grouplist / 指实际 list / 用 `SetFocus()` /
  `onfocus` 跳走 / 移到窗口根层级（仿 18011）/ `enable=false`。
- 结论：已全部回退。要做只能跨仓库（helper 定时写 property 驱动多个 Hero 实例互斥）。

**② OSD 字幕/音轨直选 —— 早已具备**
- `VideoOSD.xml:144/151` 就是 `DialogSelectAudio` / `DialogSelectSubtitle`，
  弹窗布局 `Includes_DialogSelect.xml:535/750`，功能零缺失。RC2 只是视觉重排。

**③ 剧集多版本弹窗 `DialogEpisodeVersions` —— 死 UI**
- `EpisodeVersion.*` 是 E4K 插件属性（GitHub 全站 0 命中、实机全空），照搬等于永不出现的空窗口。

**④ 焦点闪描边 —— 真机证伪**
- focusedlayout 重建时叠加层动画事件不重放，控件停在透明。详见 `handover-2026-11-19.md` §4.3。
