## 1. 分工

### 我自动跑（JSON-RPC + PrintWindow + 日志）
1. 首页默认页签、两行内容、空状态文案（三种条件）；

### 你只需要看
1. 间距顺不顺眼、色光三档哪档舒服；
2. 版本面板大小/信息密度；
3. 相似列表是否好用（独立视频窗口 vs 弹内面板）；
4. 18:9 背景上下裁切是否自然、16:9 是否满屏。

## 3. 可直接复制的探针

```bash
# 当前窗口（应为主界面/视频信息）
curl -s -u kodi:kodi -X POST http://127.0.0.1:8080/jsonrpc \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"GUI.GetProperties","params":{"properties":["currentwindow"]},"id":1}'

# 多版本节点（那山那人那狗 = 24，应返回 2 个版本）
curl -s -u kodi:kodi -X POST http://127.0.0.1:8080/jsonrpc \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"Files.GetDirectory","params":{"directory":"videodb://movies/titles/24/1/","properties":["title"]},"id":2}'

# 详情页技术标识（打开 24 的详情后执行；VideoResolution 等不应为空）
curl -s -u kodi:kodi -X POST http://127.0.0.1:8080/jsonrpc \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"XBMC.GetInfoLabels","params":{"labels":["ListItem.DBID","ListItem.VideoResolution","ListItem.VideoCodec","ListItem.HdrType","ListItem.AudioCodec","ListItem.AudioChannels","ListItem.HasVideoVersions"]},"id":3}'

# 相似路由（Emby 离线应返回“无法连接 Emby 服务器”，不能卡目录）
curl -s -u kodi:kodi -X POST http://127.0.0.1:8080/jsonrpc \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"Files.GetDirectory","params":{"directory":"plugin://script.mistuary.helper/?mode=similar&type=movie&dbid=24","properties":["title"]},"id":4}'
```

## 5. 已知问题 / 不做误判

1. `12年级的失败` 的 Kodi `streamdetails` 为空 → 无技术标识，不是皮肤回归。
2. Emby 当前 `No authenticated Emby session` → 图片/相似/技术标识可能缺失；先登录再测。
3. 运行中的皮肤如果没 F5，版本面板/空状态文案不会出现；截图里看到的仍是旧 XML。
4. 版本面板唯一未知点：`ListItem.HasVideoVersions` 是否对 5 部双版本片为真。若按钮不出现，改入口。
5. 相似入口只在 `movie/tvshow` 且 `DBID>0` 时出现；Emby 动态条目（DBID=0）暂不显示。
