### 4.3 三件已判定「不做」的事（2026-11-19 查实，别重做）

**① 焦点闪描边（真机证伪，已撤销）**
- 出处是 RC2 母版 `D:/下载/AI/skin.estuary.nara-RC2/xml/Includes_GlassFocus.xml`：
  两层（常亮玻璃底 + 1.3px 描边闪 140ms 亮 / 停 140ms / 360ms 淡出）。
- 曾在 `View_54_InfoWall.xml` 的 `InfoWallMovieLayout` 按方案 A 加过一层 ring PNG 闪描边，
  **真机验证后撤销**。根因：RC2 用魔改内核属性（`material="glass"` / `cornerborder`，63 文件），
  官方 K22 全不认；且 focusedlayout 重建时叠加层的 Focus/Visible 动画事件不重放，
  控件停在透明态。诊断证据：无动画的绿色常显层能渲染（PrintWindow 抓到 554 绿像素），
  一旦加 fade 动画（Focus/Visible、有无 `initial`、1.4s/3s）就恒为 0 → 事件不触发。
- 结论：本皮肤纯官方 K22，此效果无法可靠实现。**别再试。**

**② OSD 字幕/音轨直选——我们早已具备**
- RC2 4.1.0 changelog 写「用直接的字幕/音轨选择器替换 OSD 按钮」，看似新功能，
  实际我们 `VideoOSD.xml:144/151` 就是 `DialogSelectAudio` / `DialogSelectSubtitle`，
  弹窗布局 `Includes_DialogSelect.xml:535/750` 同名同结构，功能零缺失。
- RC2 的差异只是视觉重排（图标 36→60、变量 `StreamCodecVar` → map `AudioCodecTextMap`、
  拆文件去 `Nara` 前缀）。**不移植。**

**③ 剧集多版本弹窗 `DialogEpisodeVersions`——死 UI**
- GitHub 全站搜 `EpisodeVersion` / `EpisodeVersion.Tag` = 0 命中，官方 Kodi 核心无此属性。
- RC2 靠表达式 `VideoInfoGenEpisodeVersionsAvailable` =
  `Window(Home).Property(EmbyPluginX)==1 + Window.Property(VideoInfo.GenEpisodeVersions)==true`，
  是 E4K 插件侧生成的。实机探针这几个属性全空（E4K 虽装）；我们 helper 仓也搜不到。
- 照搬 = 永不出现的空窗口。**不做。**

### 4.4 真机测试的三个坑（下次省时间）
- **F5 重载**没有 JSON-RPC 方法（`ExecuteAction` 枚举无 reloadskin）；用 Python ctypes
  `keybd_event(VK_F5)` 发给 Kodi 窗口，日志见 `skin loaded...` 即成功。
- **抓图只能用 PrintWindow**（`docs/scratch/cap_kodi_pw.ps1`，且必须从 PowerShell 工具直接调，
  从 Bash/Python subprocess 调 ps1 会被安全策略拦）；**ImageGrab 抓的是前台窗口**，
  WorkBuddy 常抢前台 → 抓到的是 WorkBuddy 不是 Kodi，会得出一堆假阴性结论。
- **屏参**：`Settings.SetSettingValue(videoscreen.screenmode, DESKTOP)` 可从 1920×1009 窗口
  切回 1920×1080 全屏（18:9 → 16:9 需再 F5）。Kodi 22 没有 `Settings.SetSystemSetting`。
- **音乐播不了的根因**：音乐库 515 首全是 Emby 代理 `http://127.0.0.1:57342/...`，
  NAS `192.168.50.250:5005` 离线时全部解码失败；E4K 还会不断往播放列表塞坏条目。
  本地 FLAC（`D:/音乐/`）要用 `Playlist.Add` + `Player.Open(position)` 才能播。
  `music.jpg` 截图等 Emby 恢复后**用户手动**做，AI 不代劳。
